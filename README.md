# Compartment-specific immunity in irreversible pulpitis

Analysis code and result tables for the manuscript

> **Compartment-specific immunity in irreversible pulpitis centres on an inflammatory venule**
> Zhongzhen Ren (School of Stomatology, Shandong Medical and Pharmaceutical University, Yantai, China)

This repository contains the R scripts and numerical outputs behind every figure and table of the
manuscript. All analyses are secondary analyses of public data; no new sequencing data were generated.

---

## 1. Data sources

| Dataset | Use in the paper | Accession |
|---|---|---|
| GSE77459 | Bulk transcriptome, 6 healthy vs 6 irreversible pulpitis | GEO, Agilent GPL16956 |
| GSE185222 | Single-cell RNA-seq, 4 samples, 6,582 cells, 12 cell types + mixed/low-quality class | GEO |
| E-MTAB-14896 | Three-stage single-cell cohort, 12 patients, 53,407 cells | ArrayExpress |
| GSE193448 | 808 nm photobiomodulation qPCR panel, 90 wells (84 targets + 5 housekeeping + 1 DNA control) | GEO |

Download the processed matrices from the accessions above. Raw GEO/ArrayExpress files are **not**
redistributed here, both to respect the original submitters' terms and to keep the release small.
The large expression RDS files are likewise excluded; they are regenerated by the preparation
scripts.

## 5. Statistical notes

- Composition tests are Kruskal-Wallis across the three stages on patient-level values; Wilcoxon
  tests compare advanced versus healthy patients.
- Leave-one-patient-out analysis (`56_endo_ratio_lopo.R`) repeats every proportion test after
  omitting each of the 12 patients in turn (Supplementary Table 10).
- Communication axes were tested twice: pooled normalised share (Supplementary Table 9) and
  patient-level share with 10,000 stage-label permutations preserving group sizes, two-sided
  empirical P, Benjamini–Hochberg across eight prespecified axes (Supplementary Table 11).
  Two axes changed direction between the pooled and patient-level estimates and are reported as
  not interpreted in the paper.
- Machine-learning and co-expression sections are labelled exploratory; discrimination estimates
  are internal and therefore optimistic.

## 6. Known limitations of the environment

- `29_GSEA.R` downloads MSigDB collections through msigdbr/Zenodo at run time. If that endpoint is
  unreachable, GSEA figures can be redrawn from the stored tables with `86_redraw_gsea.R`, which
  performs no new computation.
- CellChat, BisqueRNA and monocle3 were not installable under Bioconductor 3.22 on the authors'
  system; the analyses use the lighter alternatives implemented here (nnls for deconvolution,
  slingshot for pseudotime, an explicit ligand-receptor outer-product model for communication).
- The full E-MTAB-14896 matrix must be handled patient by patient; densifying it in one step
  exceeds available memory.
- Absolute output paths inside the scripts reflect the original machine. Set a single base
  directory at the top of each script before running.
